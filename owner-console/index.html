How changes are made here

What the server allows, uses and charges, without hand-editing Firestore. Each group saves on its own (or all of them at once from the bar at the bottom), after a check by the server and a confirmation; sensitive ones ask you to type a word. This page makes only small, safe changes (each setting says how far); anything larger is made with the admin command, which needs your own cloud credentials. Every change is recorded, logged and emailed to you.

Providers

Who writes the recipe text and draws the pictures: four switches, each switched on its own. A fallback is asked once when its model fails for capacity, a refused key or an empty balance.
